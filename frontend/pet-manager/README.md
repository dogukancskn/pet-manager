# 🐾 Pet Manager

Pet Manager, evcil hayvanların kayıt, listeleme, güncelleme ve silme işlemlerinin gerçekleştirilebildiği bir web uygulamasıdır.

Proje, Web Geliştirme - JavaScript eğitimi kapsamında ReactJS kullanılarak geliştirilmiştir.

## 🚀 Kullanılan Teknolojiler

- ReactJS
- Vite
- JavaScript
- Bootstrap 5
- Axios
- React Router
- HTML5
- CSS3

## 📌 Proje Özellikleri

Uygulama içerisinde aşağıdaki işlemler gerçekleştirilebilir:

- 🐾 Evcil hayvan ekleme
- 📋 Evcil hayvanları listeleme
- ✏️ Evcil hayvan bilgilerini güncelleme
- 🗑️ Evcil hayvan silme
- 🔎 Evcil hayvan detaylarını görüntüleme
- 💉 Aşı bilgilerini yönetme
- 📱 Responsive kullanıcı arayüzü

## ⚙️ Kurulum

Projeyi bilgisayarınıza indirdikten sonra proje klasöründe terminali açın.

Gerekli paketleri yüklemek için:

```bash
npm install
```

Projeyi geliştirme ortamında çalıştırmak için:

```bash
npm run dev
```

Terminalde gösterilen localhost adresini tarayıcıda açarak uygulamayı kullanabilirsiniz.

## 🔨 Production Build

Projeyi production ortamı için build etmek için:

```bash
npm run build
```

Build işleminin başarılı olduğunu kontrol etmek için:

```bash
npm run preview
```
